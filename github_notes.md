[add new repository:](https://docs.github.com/en/get-started/git-basics/managing-remote-repositories)



git remote add origin https://github.com/OWNER/REPOSITORY.git



verify new remote:

git remote -v



changing an existing remote repository (takes two arguments):

git remote set-url originhttps://github.com/OWNER/REPOSITORY.git

change current user Name:
git config --global user.name "bstall-sudo"
